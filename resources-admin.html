How this actually works

This site is static HTML with no server or database, so there's no way for a form like this to truly "publish" a file for visitors automatically. Here's the real process, step by step:

  1. Upload the actual PDF or PPT file to your hosting, inside assets/resources/parents/ or assets/resources/professionals/ (create these folders the first time).
  2. Fill in the form above and click Generate Code.
  3. Copy the generated snippet.
  4. Open resources-parents.html or resources-professionals.html in a text editor, find the <!-- Resource cards go here --> comment inside the downloads grid, and paste the snippet just above it.
  5. Remove the style="display:none;" from that grid's opening tag (and delete or hide the "coming soon" message above it) once at least one real resource is listed.
  6. Save the file and re-upload it to your hosting.
